# Haas

Haas organises exploratory conversations and sustained work with their artefacts.

## Language

**Chat**:
A standalone conversation for exploring a question or testing an idea, with its own artefacts.
_Avoid_: Project, run

**Project**:
A named, longer-term body of work containing related conversations and shared artefacts.
_Avoid_: Chat, run

**Conversation**:
A sequence of messages and tool results, either standalone as a chat or belonging to a project.

**Artefact**:
A file imported or produced while working in a chat or project.
_Avoid_: Attachment when referring to a produced file

**Git tracking**:
Optional local version history for a chat or project, including its conversations and artefacts.
